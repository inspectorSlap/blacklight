# Extraction record

This is a new, local derivative workspace. The detailed source-to-export mapping and original hashes are retained separately in a private extraction record. They are not embedded in this prospective public package.

## Retained

- A sanitized complete snapshot of the independent harness's Python modules, stored disabled in `incubator/harness/`.
- A runnable subset containing exact oracle, separate reference, checks, deliberate mutants, fixture builders, registry, local runner, and dispatch/sequential helpers.
- Selected operational engineering source as disabled design assets.
- Synthetic mathematical anchors and their derivations.
- Selected engineering Markdown notes, clearly labelled historical and not current validation.

## Excluded

Original target/vendored engine code, corpus and observed study outputs, result archives, private preregistration and research narrative, operator approvals and execution authorities, secrets and environment settings, model sessions, machine configuration, prior Git history, one-off approval/release record generators, and unrelated projects.

## Deliberate changes

Schema and environment-variable namespaces are neutral. Specimen IDs are synthetic. Source-specific research/organization/person labels and local paths are scrubbed. Generic profile labels C1–C5 replace the original hypothesis labels; calculations and thresholds remain profile-specific.

The registry builder's inherited approval is reset to pending, including the generated status label. Local reports never grant external execution authority. At extraction, the CLI replaced the study launcher with offline build/demo/status commands. Phase 2 added a separate bounded target probe for local executables and literal-loopback HTTP; vendored-engine and campaign execution remain unimplemented. The active self-qualification gate treats blocked/unmappable results as blocking, alongside failures.

Generated artifacts go into a separate workspace, not the source tree. All preserved incubator Python files fail immediately before imports/actions. The original files have not been edited, and their hashes are checked against the private extraction record.

## Scrub boundaries

Automated scans check private labels, paths, likely credentials, personal contact patterns, cache files and symlinks. Manual selection excludes sensitive data directories entirely. The scan is a practical release aid, not proof that all information is non-sensitive. Incubator notes retain generic historical algorithm/engineering details and version references, not current qualification claims.

This is isolation and preparation for design work, not permission to publish, a new research approval, or a universal-framework release.
