# Implementer role template

Implement the target against the operator's frozen public contract in a separate workspace. Publish the allowed transport schema and stable identity. Do not supply target source, internal tests or observed study outcomes to the harness role before its expectations are frozen. Record assumptions and unsupported behavior. Build synthetic examples that disclose no private data.

This document is a role template, not enforcement or an execution authorization.

Use the [Phase 4 workflow](../docs/AGENT-WORKFLOW.md) to prepare a contract-only handoff. Keep source and private results outside the reviewer mount. The contract allowlist narrows the file set, but you must review its text before release.
