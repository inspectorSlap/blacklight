# Independent harness role template

Work only from the frozen public contract and permitted interface. Derive expected results without consulting target source or copying target responses. Construct clean scenarios, symbolic anchors where possible, targeted broken variants and a two-sided coverage registry. Record ambiguities rather than guessing. Freeze the oracle, tests and acceptance rule before target evaluation.

Use a separate process/workspace with verified access controls. Do not claim independence from prompt instructions alone. After a frozen black-box result, separately authorized source review may explain findings. Every finding should name the requirement, reproducer, expected behavior, observation and consequence.

This template does not start an agent, enforce isolation or grant permission to run a target.
