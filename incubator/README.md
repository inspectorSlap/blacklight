# Disabled design archive

These are scrubbed copies of implementation assets worth retaining for generalization. They are not part of the runnable prototype. Each Python module raises before imports or actions, so accidental execution cannot contact an old target, read missing private artifacts, resume a study run or manufacture inherited approvals.

The harness snapshot preserves later ordered-evidence, campaign, evidence-retention and release-control work. The operational subset preserves proxy, supervisor, attestation, continuation and launch-safety designs. They still contain generic legacy artifact/version coupling; supporting arbitrary studies requires architectural work, not just deleting the guards.

No engine implementation, private contract, historical approval record, live result, token or machine configuration is included. Active runtime modules must not import this archive. See the architecture and generalization plan before promoting code into the supported package.
